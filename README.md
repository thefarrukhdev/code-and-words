# Code and Words

> A collection of poetic terminal scripts, CLI art, and visual stories built with code.

This repository serves as a personal diary and a creative canvas, blending programming with storytelling. Each folder contains a unique project designed to run in the terminal, exploring how code can be used to express thoughts, poetry, and philosophy.

## Projects

* **`UmrOtmoqda_Video`** — A beautifully timed terminal typing effect synchronized with audio, illustrating the fleeting nature of time like a flowing river.
* **`TheOnlyWayToGetThere_Video`** — A motivational terminal typing experience precisely synchronized to voice and rhythm, capturing the mindset of relentless action ("It's the only way to get there").
* **`TashlabKetganJoydaman_Video`** — A poignant, emotionally resonant terminal poem synchronized with voice and music, reflecting on longing, struggle, and steadfast loyalty ("Tashlab ketgan joydaman").
* **`IfYouDontFail_Video`** — An electrifying terminal typing performance synchronized to Denzel Washington's legendary words on risk, failure, and growth ("If you don't fail, you're not even trying").
